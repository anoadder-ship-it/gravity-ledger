# Externe review van 10 november 2026 (historisch verslag)

Deze review is uitgevoerd op de stand vóór stap 1 en raakte `src/` niet aan;
hij gebruikte alleen de publieke API van dat moment. De bevindingen en hoe ze
nu bewaakt worden:

- **R1:** een noot die nooit was opgenomen kon besteed worden, waarna de
  uitgang een echte, bewijsbare noot was (waarde uit het niets); gesloten in
  stap 7 doordat de keten zelf de commitment en het blad uitrekent en
  lidmaatschap controleert, bewaakt door `r1_nooit_uitgegeven_munt`
  (`tests/besteding.rs`).
- **R2:** hetzelfde geheim met een ander epoch gaf een andere nullifier, zodat
  een tweede besteding slaagde; gesloten in stap 7 omdat zo'n noot geen lid is,
  bewaakt door `r2_zelfde_geheim_ander_epoch` (`tests/besteding.rs`).
- **R3:** `live()` verborg een negatieve stand van een emmer door op nul af te
  ronden; gesloten in stap 2 doordat `live()` een `Result` geeft en een lege
  emmer geweigerd wordt, bewaakt door
  `controle_8_lege_emmer_bij_inconsistente_tellers` (unit-test in
  `src/besteding.rs`). `g4_besteden_uit_lege_emmer_faalt`
  (`tests/veiligheid.rs`) eist `GeenLid` bij controle 5 en bewaakt de
  emmercontrole niet.
- **R4:** de omgekeerde richting van de behoudstest (als `check()` slaagt, zijn
  de sommen gelijk) bleek geen fout; ze staat als assert in
  `r4_behoud_omgekeerd` (`tests/veiligheid.rs`).
- **R5:** de boom (elk bewijs geldt alleen voor zijn eigen positie en blad, en
  het venster aanvaardt precies de laatste 64 wortels) bleek geen fout; dit
  staat als assert in `r5_boom_en_venster` (unit-test in `src/tree.rs`).
- **R6:** in `dsh` had de tag geen lengteprefix, zodat twee verschillende
  combinaties van tag en delen dezelfde hash konden geven; gesloten in stap 1
  doordat de lengte vóór de tag staat, bewaakt door
  `g5_tag_en_delen_zijn_eenduidig` en `g5_dsh_volgt_de_codering`
  (`tests/veiligheid.rs`).

## Oorspronkelijke code

> **Historisch.** Dit is de code van de review zoals hij op 10 november 2026
> werd aangeleverd. Hij compileert niet meer tegen de huidige API (onder meer
> `spend::spend` bestaat niet meer, `Note` heeft een veld `owner`, de velden

// Externe review 10 november 2026. Raakt src/ niet aan; alleen de publieke API.
use gravity_ledger::spend::{live, mint_to_ledger, spend};
use gravity_ledger::conservation::{Shape, zero};
use gravity_ledger::hash::dsh;
use gravity_ledger::{Accumulator, ChainId, Ledger, Note, Secret};

fn chain() -> ChainId { ChainId([3u8; 32]) }
fn noot(level: u8, epoch: u64, k: u8) -> Note { let mut s=[0u8;32]; s[0]=k; s[1]=level; Note{level,epoch,secret:Secret(s)} }

/// R1: een noot die nooit is opgenomen kan besteed worden; de uitgang is daarna
/// een echte, bewijsbare noot in de accumulator. Waarde uit het niets.
#[test]
fn r1_besteden_van_nooit_opgenomen_noot() {
    let mut l = Ledger::new(chain());
    assert_eq!(l.acc.len(), 0);
    let nep = noot(32, 0, 1);            // hoogste denominatie, nooit gemint
    let uit = noot(32, 0, 2);
    let r = spend(&mut l, &nep, &uit);
    println!("R1 spend van niet-geminte noot: {:?}", r.is_ok());
    println!("R1 accumulator bevat nu {} noot(en)", l.acc.len());
    let p = l.acc.proof(0).unwrap();
    println!("R1 uitgang heeft geldig lidmaatschapsbewijs: {}", l.acc.verify_at(&p, 0, &uit.commitment(&l.chain), &l.root()));
    println!("R1 live in emmer (0,32): {}", live(&l.buckets, &l.spent, 0, 32));
}

/// R2: zelfde geheim, ander epoch-veld -> andere nullifier -> tweede besteding slaagt.
#[test]
fn r2_zelfde_geheim_ander_epoch() {
    let mut l = Ledger::new(chain());
    let echt = noot(10, 0, 7);
    mint_to_ledger(&mut l, &echt);
    let a = spend(&mut l, &echt, &noot(10, 0, 8)).is_ok();
    let mut vals = echt; vals.epoch = 1;   // nooit zo opgenomen
    let b = spend(&mut l, &vals, &noot(10, 0, 9)).is_ok();
    println!("R2 eerste besteding: {a}, tweede met gewijzigd epoch: {b}, noten in boom: {}", l.acc.len());
}

/// R3: live() verbergt een negatieve stand.
#[test]
fn r3_live_verzadigt() {
    let mut l = Ledger::new(chain());
    for k in 0..3 { let _ = spend(&mut l, &noot(5, 9, k), &noot(5, 1, 100 + k)); }
    println!("R3 emmer (9,5): opnames {:?}, bestedingen {:?}, live() = {}", l.buckets.get(&(9,5)), l.spent.get(&(9,5)), live(&l.buckets, &l.spent, 9, 5));
}

/// R4: omgekeerde richting van de behoudstest: als check() slaagt, zijn de sommen gelijk.
#[test]
fn r4_behoud_omgekeerd() {
    let mut x: u64 = 0x9E3779B97F4A7C15; let mut nx = |m: u64| { x ^= x << 13; x ^= x >> 7; x ^= x << 17; x % m };
    let (mut ok, mut fout) = (0u32, 0u32);
    for _ in 0..2_000_000 {
        let mut s = Shape::default();
        let lo = nx(31) as usize;
        for d in lo..lo + 3 { s.ins[d]=nx(3) as u32; s.outs[d]=nx(3) as u32; s.fee[d]=nx(2) as u32; s.splits[d]=nx(2) as u32; s.merges[d]=nx(2) as u32; }
        if s.check().is_ok() { ok += 1; if Shape::total_value(&s.ins) != Shape::total_value(&s.outs) + Shape::total_value(&s.fee) { fout += 1; } }
    }
    println!("R4 geldige vormen: {ok}, daarvan met ongelijke som: {fout}");
    assert_eq!(fout, 0);
    // rand: splits/merges op het hoogste niveau
    let mut s = Shape::default(); s.ins[32]=1; s.splits[32]=1; s.outs[31]=2; assert!(s.check().is_ok());
    let mut s = Shape::default(); s.merges[32]=1; s.ins[31]=2; s.outs[32]=1; assert!(s.check().is_ok());
    let _ = zero();
}

/// R5: boom. Elk bewijs klopt alleen voor zijn eigen positie en blad; vensterrand.
#[test]
fn r5_boom_fuzz() {
    let leaf = |i: usize| dsh(b"t", &[&(i as u64).to_le_bytes()]);
    let mut kruis = 0u32; let mut goed = 0u32;
    for n in 1..=70usize {
        let mut a = Accumulator::new(); for i in 0..n { a.push(leaf(i)); }
        let root = a.root();
        for i in 0..n {
            let p = a.proof(i).unwrap();
            assert!(p.verify(i, &leaf(i), &root)); goed += 1;
            for j in 0..n { if j != i { if p.verify(j, &leaf(i), &root) || p.verify(i, &leaf(j), &root) || p.verify(j, &leaf(j), &root) { kruis += 1; } } }
            // ingekort en verlengd pad
            let mut q = p.clone(); if q.path.pop().is_some() { assert!(!q.verify(i, &leaf(i), &root)); }
            let mut q = p.clone(); q.path.push((root, true)); assert!(!q.verify(i, &leaf(i), &root));
        }
    }
    println!("R5 geldige bewijzen: {goed}, bewijzen die ook voor een andere positie of blad slagen: {kruis}");
    // venster: precies 64 oude wortels
    let mut a = Accumulator::new(); let mut roots = vec![]; for i in 0..200 { a.push(leaf(i)); roots.push(a.root()); }
    let acc: Vec<usize> = (0..200).filter(|&i| a.accepts_root(&roots[i])).collect();
    println!("R5 venster accepteert wortels {}..={} ({} stuks)", acc[0], acc[acc.len()-1], acc.len());
    let p0 = { let mut b = Accumulator::new(); for i in 0..137 { b.push(leaf(i)); } b.proof(5).unwrap() };
    println!("R5 waar bewijs tegen wortel 136 (binnen venster): {}, tegen te oude wortel 100: {}", a.verify_at(&p0, 5, &leaf(5), &roots[136]), { let mut b = Accumulator::new(); for i in 0..101 { b.push(leaf(i)); } let p = b.proof(5).unwrap(); a.verify_at(&p, 5, &leaf(5), &roots[100]) });
}

/// R6: dsh. De tag heeft geen lengteprefix.
#[test]
fn r6_dsh_tag_zonder_lengte() {
    let a = dsh(b"x", &[b"abcdefgh12345678"]);
    // tag "x" + lengte(16) + data  versus  tag = "x" + lengte-bytes + data, geen delen
    let mut t = b"x".to_vec(); t.extend_from_slice(&16u64.to_le_bytes()); t.extend_from_slice(b"abcdefgh12345678");
    let b = dsh(&t, &[]);
    println!("R6 twee verschillende (tag, delen) met dezelfde hash: {}", a == b);
}
